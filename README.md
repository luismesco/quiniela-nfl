# La Quiniela · NFL

Autor: Luis Montañez Escobar

Elecciones, resultados y clasificación de la quiniela recreativa. Temporada 2026, semana 6.

La página principal muestra los registros recibidos. La opción **Ver maqueta** presenta una jornada ficticia para conocer las vistas de clasificación, resultados y comparación de elecciones.

Las selecciones se registran a través de Luis. Los resultados y las aportaciones se incorporan cuando se confirman. Los datos de la maqueta se mantienen separados de los registros reales.
